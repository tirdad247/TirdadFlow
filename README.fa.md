# TirdadFlow 🎙️ (راهنمای فارسی)

**تایپر صوتی هوش مصنوعیِ رایگان، متن‌باز و پرتابل برای ویندوز** — دو زبانه (فارسی / English)، تیره و بدون قاب.

کلید **F9** را نگه دارید (یا روی ویجت شناور میکروفون کلیک کنید)، صحبت کنید، رها کنید — متن شما با هوش مصنوعی تبدیل به متن شده و مستقیم در همان برنامه‌ای که دارید استفاده می‌کنید پیست می‌شود. بدون اشتراک. بدون حساب کاربری. با کلید رایگان خودتان.

## ✨ امکانات

- **ضبط با نگه‌داشتن کلید** — هات‌کی سراسری F9 یا ویجت شناور همیشه‌روی‌صفحه
- **سرویس‌های کاملاً رایگان** — **Groq** (Whisper large-v3) و **Google Gemini** (Flash)؛ با کلید رایگان خودتان
- **تعویض خودکار کلید** — چند کلید را با کاما جدا کنید؛ سهمیه یکی تمام شد، بعدی امتحان می‌شود
- **تعویض خودکار سرویس** — سهمیه روزانه Groq تمام شد؟ خودش می‌رود سراغ Gemini
- **رابط دو زبانه** — فارسی RTL و انگلیسی LTR با یک کلیک
- **کلیپ‌بورد امن** — بعد از پیست، محتوای قبلی کلیپ‌بورد شما برگردانده می‌شود
- **پرتابل** — یک فایل exe تنها؛ کانفیگ و لاگ کنار خودش، بدون نصب
- **حریم خصوصی** — بدون هیچ تلمتری؛ صدا فقط در رم می‌ماند و روی دیسک نوشته نمی‌شود ([جزئیات](SECURITY.md))
- **📋 دکمه کپی لاگ** — با یک کلیک، گزارش خطا را برای ارسال کپی کنید

## 🚀 شروع سریع

1. فایل `TirdadFlow.exe` را از بخش [**Releases**](../../releases) دانلود کنید (با فایل `SHA256SUMS.txt` صحتش را بررسی کنید).
2. اجراش کنید — نیازی به نصب نیست.
3. یک کلید API رایگان بگیرید (پایین) و در برنامه پیست کنید. **F9** را نگه دارید، صحبت کنید، رها کنید. تمام!

### 🔑 دریافت کلید رایگان

| سرویس | لینک دریافت کلید | نکته |
|---|---|---|
| **Groq** (پیش‌فرض، سریع) | [console.groq.com/keys](https://console.groq.com/keys) | Whisper large-v3 · در ایران نیاز به VPN |
| **Google Gemini** | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) | ⚠️ پلن رایگان ممکن است از داده‌ها برای آموزش استفاده کند — برنامه هشدار می‌دهد |

- چند کلید دارید؟ با کاما جدا کنید — تعویض خودکار.
- هر دو سرویس را پر کنید و **«سوییچ خودکار سرویس»** را روشن بگذارید تا همیشه کار کند.

## 🛠️ اجرا از سورس

```bat
pip install -r requirements.txt
python whisper_flow.py
```

## 📦 بیلد فایل پرتابل

```bat
pyinstaller --noconsole --onefile --clean --name "TirdadFlow" --collect-binaries _sounddevice_data --collect-submodules sounddevice whisper_flow.py
```

خروجی: `dist\TirdadFlow.exe` — کاملاً پرتابل.
